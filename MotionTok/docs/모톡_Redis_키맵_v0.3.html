Refresh Token 세션 · 로그아웃 시 DEL = 서버측 무효화 (JWT_REFRESH_EXPIRATION_MS 기본값과 동일하게 맞춰짐).

갱신은 "검사 + 회전"을 Lua 한 덩어리로 돌린다(원자성). 나눠 실행하면 동시에 들어온 두 갱신이 각자 회전해 클라이언트가 든 토큰이 죽는다. 회전 직후 30초(grace) 안에 prevHash가 오면 회전 없이 통과시키고, 그 창을 넘긴 옛 토큰은 재사용으로 보고 키를 DEL한다.

오프라인 수신자의 미배달 귓속말 수신함. 발신 시 상대가 오프라인이면 개인 큐 배달 대신 여기 적재한다(종전의 WHISPER_TARGET_OFFLINE 거절은 제거). 엔트리 필드는 대화 로그와 같고, 여기에 대화 Stream이 발급한 원본 whisperId를 추가로 실어 나른다 — 회수분·이력·실시간 수신분을 클라이언트가 whisperId 하나로 중복 제거하기 위함(수신함 Stream 자체의 엔트리 ID는 쓰지 않는다). 대화 원장(whisper:{a}:{b})과의 역할 분담: 원장은 대화 내용의 진실, 이 키는 "안 배달된 게 있다"는 수신자 기준 신호 — 수신함이 날아가도 내용은 원장에 남는다. 회수는 GET /api/friends/whispers/pending이 비우면서 반환(읽은 엔트리만 XDEL — 키 통째 DEL은 회수 중 도착분을 지운다).
