인증 · 오류 규격 공통

인증 — 대부분의 엔드포인트는 Authorization: Bearer <accessToken> 필요. 로그인/가입/소셜/게스트/공개 조회(방 목록·게임·곡)는 인증 불필요. Access 만료 시 POST /auth/token/refresh로 갱신, Refresh는 Redis auth:refresh:{userId}(TTL 14d)에 저장되어 로그아웃 시 삭제=무효화.
회원가입 이메일 인증 — 가입은 3단계다. ① GET /auth/availability/email 중복 확인 → ② POST /auth/email/verify-request 6자리 코드 발송(Redis auth:email:code:{email}, TTL 5m) → ③ POST /auth/email/verify 코드 검증 후 발급된 verificationToken(TTL 5m)을 POST /auth/signup에 실어 보내면 서버가 1회 소비한다. 토큰이 없거나 만료·재사용이면 가입은 400으로 거절된다.

표준 오류 응답

400 검증 실패401 인증 필요/실패 403 권한 없음404 리소스 없음 409 충돌(중복·정원초과·잔액부족)429 요청 과다(인증번호 재발송·검증 시도 초과)

모든 오류 본문은 Error 스키마.
