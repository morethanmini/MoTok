v0.2 → v0.3 변경 이력 (2026-07-21 커밋 이력 기준)

  • rooms:public → rooms:index로 정정, "공개방만" → "공개+비공개 방 전체"로 범위 수정 (코드: LiveRoomRepository.ROOM_INDEX_KEY)
  • ① 방 섹션에 "liveroom 패키지 단일화" 메모 추가 — 인메모리 room(임대연) 패키지 삭제(b8c38ee, 11:02) 반영
  • ⑤ 인증 토큰 섹션에 누락돼 있던 이메일 인증 키 4종(auth:email:code/verified/cooldown/sent) 신규 추가 — EmailVerificationService 실구현 기준
  • 모든 섹션에 ✅ 구현됨 / 📋 미구현 배지 부여 — ②③④⑥은 코드 0줄로 확인, 순수 설계 단계임을 명시
  • ④ 섹션에 "Redis Pub/Sub 자체가 코드에 없고 현재 브로드캐스트는 STOMP 인메모리 브로커" 사실 확인 노트 추가
  • playerKey 규격 카드에 SignalMessage 타입 정정(5f4f47d) 반영
  • PNG(모톡_Redis_키맵_v0.2.png)는 원본 그대로 보존, 이 문서가 최신 텍스트 기준본
